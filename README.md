## About This Project

This project is based on **Data Analysis and Visualization using Microsoft Power BI**.

I used Power BI to work with a dataset, transform and organize the data, create relationships between tables, and build an interactive dashboard.

## Tools Used

* **Microsoft Power BI**
* **Power Query** – for data cleaning and transformation
* **Data Modeling** – for creating relationships between tables
* **DAX** – for creating calculations and measures
* **Power BI Visualizations** – for charts and graphs

## Work Done

In this project, I:

* Imported data into Power BI.
* Cleaned and transformed the data using Power Query.
* Created dimension and fact tables.
* Established relationships between tables.
* Created calculated columns and measures.
* Used DAX for data analysis.
* Created different visualizations and charts.
* Designed an interactive Power BI dashboard.

## Visualizations

The dashboard contains different types of visualizations such as:

* Bar Charts
* Column Charts
* Line Charts
* Pie/Donut Charts
* Cards
* Tables
* Slicers
* KPI visuals

These visualizations help understand important information from the dataset, identify trends, compare different categories, and analyze overall performance.

## Objective

The main objective of this project is to understand how **Power BI can be used to transform raw data into meaningful visual insights** through data cleaning, modeling, analysis, and visualization.

## Learning Outcomes

Through this project, I learned:

* How to import and clean data in Power BI.
* How to create a proper data model.
* How to establish relationships between tables.
* How to use DAX measures.
* How to create different charts and visualizations.
* How to design an interactive dashboard.
* How data visualization can help in understanding and analyzing data.
